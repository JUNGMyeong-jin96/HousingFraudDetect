# CLAUDE.md

포켓몬스터 골드 컨셉 기반으로 개발 하는 전세사기를 판별 하는 웹게임. 해당 프로젝트는 날이 갈수록 진화하는 전세사기 수법에 대응하기 위해 실제 사례 기반으로 전세사기 기법을 적용하여 사기인지, 정상 건축물인지 판단하는 컨셉을 가진 게임입니다.

## 기술 스택
- Next.js 16 (App Router)
- TypeScript strict mode
- Tailwind CSS v4
